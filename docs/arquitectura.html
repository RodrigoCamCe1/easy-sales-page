Capa de Datos

🗃 PostgreSQL 16 Relacional

  • users — id, email, name, password_hash, email_verified_at
  • auth_sessions — refresh_token_hash, expires_at, revoked_at (rotación)
  • magic_links — token_hash, expires_at, consumed_at (uso único)
  • user_agent_configs — config_json (JSONB, perfiles de agentes)
  • user_conversations — conversations_json (JSONB, historial)
  • user_documents — metadata de archivos (file_name, chunk_count, agent_id)

🔍 Qdrant Vector DB Cloud

  • Collection: agent_documents
  • Vectores: 1536 dims (text-embedding-3-small)
  • Distancia: Cosine similarity
  • Payload: user_id, agent_id, file_id, chunk_text, file_name
  • Índices: user_id, agent_id, file_id (keyword)
  • Batch: upsert de 100 puntos, embed de 20 chunks
Servicios Externos

🤖 OpenAI Realtime + Embeddings

  • Realtime API: gpt-4o-realtime-preview
  • WebSocket: wss://api.openai.com/v1/realtime
  • Token efímero (1h TTL) vía backend
  • VAD server-side, transcripción español
  • Embeddings: text-embedding-3-small
  • Batch de 20 inputs, 1536 dimensiones

📧 SMTP Email

  • Magic links de autenticación
  • Configurable: host, port, user, pass
  • Dev: MailHog (mock)
  • Prod: SMTP real (por configurar)

🔒 Google OAuth 2.0

  • Flujo: init → consent → callback → poll
  • Exchange code por ID token
  • Auto-crea usuario en DB
  • State con TTL de 5 min
