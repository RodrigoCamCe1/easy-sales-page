7 Plan de Migracion
FASE 1 — COMPLETADA
Audio sistema con Groq
Transcripcion del audio del sistema usa Groq Whisper.
Respuestas generadas por GPT-4o-mini via Chat Completions.
VAD local con AudioVadBuffer.
Resultado: Sistema ya no usa Realtime API.
FASE 2 — PENDIENTE
Microfono con Groq
Migrar transcripcion del mic a Groq Whisper.
Agregar segunda instancia de VAD local para mic.
Eliminar dependencia de OpenAI Realtime API al 100%.
Resultado: Cero WebSockets, cero costos Realtime.
FASE 3 — FUTURO
Optimizacion adicional
Evaluar Deepgram como alternativa a Groq para STT.
Cache de respuestas para preguntas frecuentes.
Batch processing para reducir llamadas API.
FASE 4 — FUTURO
Independencia total
Evaluar modelos open-source locales (Llama, Qwen) para respuestas.
Self-hosted Whisper para eliminar costo de STT.
Costo por minuto cercano a $0.001 (solo infra).
